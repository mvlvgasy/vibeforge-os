# BDR — Business Decision Records

> Committing strategic decisions that change the trajectory. Format `BDR<NN>`.
> A BDR is engraved: rarely modified, only extended. A revision is an explicit new BDR.

> _Empty — you fill this as you make strategic decisions. See [INDEX.md](INDEX.md)._

## Entry format

```yaml
---
id: BDR01
type: bdr
created: <YYYY-MM-DD>
last_updated: <YYYY-MM-DD>
severity: <medium|high|critical>
domain: <strategy|architecture|packaging|...>
related: []
status: <active|under-review>
---
```
